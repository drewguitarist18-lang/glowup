Same code, same score.

Run it twice and you get the same number. About 55 checks, each one a rule you can read in the source.

Every point has an address.

Each finding names the file and the line, and says how to fix it. A key it finds is never printed in full.

The audit is nearly free.

Scanning uses no AI, so /glowup audit costs almost no tokens. Claude only opens the files the scanner points at.

Fixes are measured.

The scanner runs again after every category. If the score didn't move, the fix didn't count.

It runs on its own too, with Node and nothing else: node ~/.claude/glowup/glowup-scan.mjs . What takes judgment, like whether one user can read another's data, /glowup lists separately without changing the number.

Install

Free: a Claude Code command and the small scanner it runs. Install it inside Claude Code, with a script, or by hand.

Claude Code pluginEasiest

Type it in Claude Code. No terminal, no files.

/glowup from inside Claude Code

/plugin install glowup --marketplace drewguitarist18-lang/glowup
  • Updates come through /plugin
  • Remove it any time with /plugin uninstall glowup
  • Older Claude Code: /plugin marketplace add drewguitarist18-lang/glowup, then /plugin install glowup@glowup

WindowsYour system

PowerShell

/glowup in one line

irm https://raw.githubusercontent.com/drewguitarist18-lang/glowup/main/install.ps1 | iex
  • Copies glowup.md into ~/.claude/commands
  • Restart Claude Code, then type /glowup
  • Uninstall by deleting that file and ~/.claude/glowup

macOS and LinuxYour system

Terminal or Git Bash. Needs curl and Node.js.

/glowup in one line

curl -fsSL https://raw.githubusercontent.com/drewguitarist18-lang/glowup/main/install.sh | bash
  • Copies glowup.md into ~/.claude/commands
  • Restart Claude Code, then type /glowup
  • Uninstall by deleting that file and ~/.claude/glowup
No terminal needed
