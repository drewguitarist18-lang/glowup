Add a feature.

A feature is one Markdown command plus one line in the registry. No build step, no framework.

  1. 1
    Write the command

    Make features/<name>.md and start it with a description: frontmatter line.

  2. 2
    Register it

    Add an entry to features.json. Set "stable" to ship it, or "planned" to tease it.

  3. 3
    Check it

    Run node tools/validate.mjs. It catches missing fields, duplicates and bad frontmatter.

  4. 4
    Push

    CI runs the same check and redeploys this page. Anyone who runs the installer again gets the new feature.
