For Claude Code

Turn your vibe-coded app into a professional one.

Type /glowup. It scores your project out of 100 across ten categories, fixes the worst ones in priority order, and scores it again. You get a before and after, and every change sits on its own git branch so you can undo it.

Install in one line See the scorecard

Install

Copies the command into ~/.claude/commands/. Run it once, then restart Claude Code if it's already open.

irm https://raw.githubusercontent.com/drewguitarist18-lang/glowup/main/install.ps1 | iex
curl -fsSL https://raw.githubusercontent.com/drewguitarist18-lang/glowup/main/install.sh | bash

Then, in any project: /glowup audit for a score and plan only, or /glowup for the full glow up. Run the installer again any time to pick up new features.

Add a feature

A feature is a Claude Code command: one Markdown file plus one entry in the registry. No build step.

  1. Write your command as features/<name>.md. Start it with a description: frontmatter line, like glowup.md does.
  2. Add an entry to features/features.json with the command, file, summary and status. Use "stable" to ship it, or "planned" to list it without installing.
  3. Run node tools/validate.mjs to check the registry and files.
  4. Commit and push. The installers and this page pick it up automatically.
node tools/validate.mjs
